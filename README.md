# kintone 日時基準ナビゲーションプラグイン

kintone のレコード詳細画面において、標準のレコード番号順ではなく、指定した **日付** または **日時** フィールドを基準にして「前後のレコード」へ遷移できるようにするプラグインです。

施設予約システムなど、時系列でのデータ確認が重要なアプリにおいて、直感的な操作（ボタンクリックおよびスワイプ）によるレコード移動を可能にします。

## 🚀 主な機能

- **日時・日付基準の遷移**: 任意の日時・日付フィールドを基準に、時系列で「前へ」「次へ」移動。
- **PC版対応**: プロセス管理（アクション）ボタンの横にボタンを自動配置し、業務の流れを妨げない UI を提供。
- **モバイル版対応**: スマートフォン専用のヘッダー領域にボタンを表示。
- **スワイプ操作サポート (モバイル)**: 画面を左右にスワイプすることで、直感的に前後のレコードへ移動可能。
- **簡単設定**: プラグインの設定画面から、アプリ内の対象フィールドを選択するだけで導入完了。

## 📦 インストール方法

1. リポジトリ内の `plugin.zip` をダウンロードします（または自身でビルドします）。
2. kintone のシステム管理画面からプラグインを読み込みます。
3. 適用したいアプリの設定画面で「日時基準ナビゲーションプラグイン」を追加します。
4. プラグインの「設定（歯車アイコン）」を開き、基準とする日付または日時フィールドを選択して保存します。
5. 「アプリを更新」をクリックして反映させます。

## 🛠️ 開発・ビルド手順

自身の環境でカスタマイズしてビルドする場合の手順です。

### 前提条件
- Node.js インストール済み

### 手順
1. リポジトリをクローンします。
2. 依存関係をインストールします:
   ```bash
   npm install
   ```
3. ソースコードを編集します（`src/` 内のファイル）。
4. プラグインをビルドします:
   ```bash
   npm run build
   ```
5. ルートディレクトリに `plugin.zip` が生成されます。

## 📝 注意事項
- このリポジトリには秘密鍵（`.ppk`）は含まれていません。初回ビルド時に自動生成されます。
- スワイプ操作は、縦方向のスクロールと干渉しないよう、横方向の移動量が大きい場合のみ反応するように設計されています。
